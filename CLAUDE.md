# CLAUDE.md

## Documentation

- When you delegate documentation to the scraibe agent (`scraibe` or
  `scuq-scraibe`), tell it not to add a draft notice to any file. Do not
  write "This document is a draft. A human must review it before it is
  committed." or a similar line into a README, docs/, CHANGELOG, or other
  file. The agent may still say in its report that the text is a draft.
